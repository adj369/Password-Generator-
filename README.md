

* Python Password Generator & Strength Checker 

A beginner Python mini-project

- Features
* Custom Password Generator: Generates random passwords based on user-selected length and character preferences (uppercase, numbers, symbols).
* Password Strength Analyzer: Checks any password and scores it out of 5 based on length and character variety.
* Session History: Lets you label and view passwords generated during the current session.

- Concepts Used
- Python `random` module (`random.choice`)
- String manipulation & concatenation
- Lists (`append`, indexing)
- Functions (`def`), `for` and `while` loops, and `if-elif-else` conditions

- How to Run
1. Ensure Python 3 is installed.
2. Run the file in your terminal:
   ```bash
   python password_generator.py
